Privacy Policy

Last updated: November 2026

Montage is a personal desktop application that runs locally on its owner's own computer. It has no server and does not collect data about anyone.

1. Who uses it

Montage is used by one person only: its owner. It is not offered to the public, so there are no other users whose data could be collected.

2. What is stored, and where

When the owner connects a YouTube, Facebook, Instagram or TikTok account, the application receives from the platform an access token and the public name of the connected account (for example a channel or profile name). The application also keeps the owner's videos and project files. All of this is stored only in files on the owner's own computer, never on an online server.

3. What is sent to the platforms

When the owner decides to publish, the application sends the chosen video, its title and its description to the platform the owner selected, using that platform's official API. For TikTok, the application requests the user.info.basic permission (to display the connected account's name) and the video.publish permission (to post the owner's own videos to his own account). Nothing else is requested or read.

4. What Montage does not do

  • It does not collect, store or process personal data about any other person.
  • It does not send any data to a server run by the application's owner, because there is none.
  • It does not sell, share or disclose data to third parties.
  • It does not use cookies, analytics, advertising or tracking.
  • It is not directed at children and has no way for anyone else to use it.

5. Local address

The application opens a page on the owner's computer itself (an address starting with localhost). This address cannot be reached from the Internet. It is used for the application's screens and to receive the platform's sign-in response when the owner connects an account.

6. Deleting data

The owner can disconnect an account at any time in the application, which removes its access token from the computer, and can revoke the application's access from the security settings of the platform concerned (TikTok, Google, Meta). Deleting the application's files from the computer removes everything it stored.

7. Changes

This policy may be updated. The latest version is always on this page.
