Privacy Policy

Last updated: November 2026

Montage is a personal desktop application used by a single person (its owner). It runs only on the owner's own computer.

What the application stores

When the owner connects a YouTube, Facebook, Instagram or TikTok account, the application receives an access token and the public name of the connected account (for example the channel or profile name). These are stored in a file on the owner's own computer and nowhere else.

What the application does not do

  • It does not collect, store or process personal data about any other person.
  • It does not send data to any server operated by the application's owner.
  • It does not sell, share or disclose data to third parties.
  • It does not use analytics, advertising or tracking.

How data is used

The tokens are used only to publish videos, chosen by the owner, to the owner's own accounts through the official platform APIs. The only data sent to a platform is the video, its title and its description.

Deleting data

The owner can disconnect an account at any time in the application, which removes its token from the computer, and can also revoke access from the security settings of the platform concerned.
